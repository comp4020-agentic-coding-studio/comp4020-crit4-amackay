# Crit 4 — reflection


## What was the breakthrough that moved the work forward?

The agent doesn't always know what is "obvious to a user". So agent-written explanatory prose quite naturally ends up overexplaining some things that seem bleedingly obvious. The general fix for this was to increase communication in the other direction - I need to let the agent know which things are obvious and don't need explaining.


## What did this work change about who I want to be as a software developer?

Agentic coding means easier progress means easier to make "just one more improvement". It's easier to work on more ambitious projects, but deciding when things are "good enough" and finishing up a project is just as difficult as ever.
